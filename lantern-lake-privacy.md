# Lantern Lake — Privacy Policy

Last updated: September 4, 2026

Lantern Lake is an offline single-player game developed by Darwvin.

## Data collection and sharing

Lantern Lake does not collect, transmit, sell, or share personal or sensitive user data with the developer or third parties through the game's runtime.

The current release contains no account/sign-in system, advertising SDK, analytics SDK, cloud crash-reporting SDK, in-app purchase system, Firebase integration, developer-operated backend, or runtime HTTP/socket integration.

The game does not request or use location, contacts, microphone, camera, advertising ID, SMS, call logs, health data, or files/media for gameplay.

## Local data

Lantern Lake stores gameplay progress and preferences locally on the device, including completed voyages and best results, discovered routes, Lantern Points, purchased upgrade levels, onboarding completion, and audio/control/accessibility/quality settings.

This local data is used only for game functionality and is not transmitted to the developer. Android cloud backup is disabled for the production build.

## Data deletion

Players can delete local game data from **Settings → Reset Local Data**. Local data can also be removed by clearing app storage in Android settings or uninstalling the game.

## Device features

Touch input, audio playback, and optional vibration/haptics are processed locally. The Android release may declare `android.permission.VIBRATE` solely for haptic feedback.

## Google Play

Google Play may independently process information when users interact with the game through Google Play. That processing is controlled by Google and subject to Google's own terms and privacy policies.

## Changes

If a future release changes data handling, this policy and the Google Play Data Safety declaration will be updated before distribution.
