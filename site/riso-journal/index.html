Riso Journal Privacy Policy

Developer: darwvin-dev · Last updated: 2026-09-11

Riso Journal (dev.darwvin.risojournal) is an offline-first Android home-screen personalization and local daily-journal app.

Data collection and sharing

The current 0.4.0 release candidate does not request Internet access, create an account, use advertising, use remote analytics, or use remote crash reporting. It does not automatically transmit journal pages, tasks, completion state, note text, focus state, theme choices, launcher information, icon setup information, installed-app coverage information, or usage data to a server.

Data stored on the device

Riso Journal stores selected palette and wallpaper composition, up to three task strings and their completion state per journal day, one short note per journal day, focus-session end time, and setup/icon-flow state in app-private local storage.

Journal History can access dated local entries. Individual journal days can be edited or deleted. Release builds do not record the local setup-friction metrics used by debuggable development builds.

Permissions and installed-app visibility

Riso Journal does not request location, contacts, microphone, camera, photos/media, SMS, call log, or broad QUERY_ALL_PACKAGES access.

The normal Android SET_WALLPAPER permission is used only when the user explicitly asks Riso to apply a wallpaper.

Icon Browser uses a narrow MAIN + LAUNCHER query to read launchable app labels, package names and launcher activities locally so it can show Riso icon coverage. Riso also declares a limited set of launcher/OEM packages for setup routing. This information is not uploaded automatically.

If the user explicitly chooses Share icon request, Android's share sheet opens with the selected app label/package/activity and the user chooses the receiving app.

Wallpaper files

Quick Setup can render the selected wallpaper locally and apply it through Android's WallpaperManager. The manual Preview & Apply path can generate a temporary PNG in app cache and grant Android's wallpaper UI temporary read access to that cached file through a private FileProvider path.

Riso Journal does not upload generated wallpapers or journal content.

Widgets and icon-pack setup

Riso Journal can ask Android/compatible launchers to pin its own widgets and can open supported launcher or OEM customization routes for its bundled icon pack.

Some launchers expose a direct icon-pack request; others require launcher settings, Samsung Theme Park, or another OEM path. Riso does not report icon success merely because another app or settings screen opened.

Stock launchers that do not expose a public arbitrary third-party icon-pack API remain Limited. If the user explicitly wants the full icon-pack experience, Riso may open an already-installed compatible launcher or its public Google Play listing using an Android ACTION_VIEW intent. Riso itself still has no Internet permission and does not download the launcher.

Journal-page sharing

When the user explicitly chooses Share page, Riso renders that journal page to a temporary PNG in app cache and passes it to Android's share sheet through a temporary FileProvider read grant. Riso does not transmit the image itself; the user selects the destination.

Backups and device transfer

Android app backup is disabled. Explicit Android backup rules also exclude app files, databases, and shared preferences from cloud backup and device-to-device transfer.

Retention and deletion

Journal pages and other local app data remain until the user changes or deletes them, clears Android app storage, or uninstalls Riso Journal.

  • Individual journal days can be deleted from Journal History.
  • Reset Riso Settings resets appearance/setup state but deliberately preserves journal pages.
  • Clearing app storage or uninstalling removes app-local journal content.
  • Temporary wallpaper-preview and journal-share files live in app cache and may be removed by Android or when app storage is cleared.

Resetting Riso settings does not remove a wallpaper that Android has already applied as the system wallpaper.

Accounts

The current release has no account system and therefore no remote account data to delete.

Google Play and external apps

Google Play, Galaxy Store, launcher apps, OEM customization tools and apps selected from Android's share sheet may independently process information when the user interacts with them. Their processing is controlled by those apps/services and their own terms and privacy policies.

Riso Journal does not receive purchase history or launcher-store account information in the current paid-upfront model.

Future changes

If a future version adds in-app Play Billing, remote analytics, crash reporting, advertising, cloud services, authentication, remote configuration, attribution, or another network service, this privacy policy and the Google Play Data safety declaration will be reviewed before that version is released.
