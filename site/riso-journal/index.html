Riso Journal Privacy Policy

Developer: darwvin-dev · Last updated: 2026-09-07

Riso Journal is an offline-first Android home-screen customization app.

Data collection and sharing

The release build does not request Internet access, create an account, use advertising, use remote analytics, or use remote crash reporting. It does not transmit the user's tasks, note, theme choices, launcher name, or usage data to a server.

Data stored on the device

Riso Journal stores the selected palette and wallpaper composition, three task strings and completion state, one short note, and setup state in app-local storage.

Release builds do not record the local tester metrics used by debuggable development builds.

Backups and device transfer

Android app backup is disabled. Explicit Android backup rules also exclude app files, databases, and shared preferences from cloud backup and device-to-device transfer.

Launcher visibility

The app declares narrow visibility for the current Android HOME launcher only so it can display launcher-specific setup guidance. It does not request broad QUERY_ALL_PACKAGES access.

Wallpaper files

When the user asks to apply a wallpaper, Riso Journal generates a temporary PNG in the app cache and grants Android's wallpaper UI temporary read access to that cached wallpaper file through a private FileProvider path.

Retention and deletion

Local theme content remains until the user changes it, uses Reset Riso Settings, clears the app's storage, or uninstalls the app. Temporary wallpaper files live in app cache and may be removed by Android or when app storage is cleared.

Resetting Riso settings does not remove a wallpaper that Android has already applied as the system wallpaper.

Accounts

The current release has no account system and therefore no remote account data to delete.

Future changes

If a future version adds remote analytics, crash reporting, advertising, cloud services, billing-related telemetry, or another network service, this privacy policy and the Google Play Data safety declaration must be reviewed and updated before that version is released.
